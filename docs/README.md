# 기능 명세

## 도메인 정의

### 비상근무자
- 평일, 휴일 순번에 **한 번 씩 배치 되어야 함**
- 평일/휴일 각 순번에 두 번 배치되면 안 됨
- `5 <= (총 근무자수) <= 35`

### 법정공휴일
근무 스케줄 배치시 **평일**이면서 **법정공휴일**의 경우에만 `(휴일)` suffix 붙음
1. 1/1 (신정)
2. 3/1 (삼일절)
3. 5/5 (어린이날)
4. 6/6 (현충일)
5. 8/15 (광복절)
6. 10/3 (개천절)
7. 10/9 (한글날)
8. 12/25 (크리스마스)

## 잘못된 입력 에러 처리
- 잘못된 입력시 `IllegalArgumentException` 발생 후 `[ERROR]`과 함께 재입력 요청

## 비상 근무할 월/요일 입력

- `,`로 구분 (e.g. `5,월`)
- 예외 상황
  - 월이 1~12가 아닌 경우
  - 요일이 월,화,...,수,목,금,토,일 이 아닌 경우 

## 평일/휴일 비상 근무 순번 입력
- 근무할 사원의 닉네임을 `,`로 구분하여 순서대로 입력한다.
- 평일 순번 또는 휴일 순번의 입력 값이 올바르지 않은 경우
  - **평일 순번부터** 다시 입력 받는다.
- 예외 상황
  - 평일 혹은 휴일 순번에 동일 닉네임이 두 번 이상 나오는 경우
  - 근무할 총 사원수가 5 이상 35 이하의 값이 아닌 경우
  - 닉네임이 평일/휴일에 각각 한 번씩 나오지 않은 경우
